# HiFi Tower

Modern world-class Hi-Fi and home theater experience for HiFi Tower Thailand.

## Direction
- Hi-end / audiophile visual language
- Modern, cinematic, interactive UI
- Mobile-first and performance-conscious
- Preserve the existing site's products, brands, promotions, articles and imagery during migration
- Frontend-first; database integration will be added later

## Source
Existing public website: https://hifitower.co.th/

## Stack
Next.js + TypeScript, deployed separately from existing projects.
